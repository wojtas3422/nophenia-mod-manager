# nophenia mod manager
Allows you to easily manage and install mods for [nophenia!](https://nophenia.net)

Based on BdE's [mp mod installer.](https://github.com/BdEgh/nophenia-mp/tree/main/mod-installer) (This wouldn't have been possible without it!)

Extra thanks to KuronSub for helping me test this before release!

# Installing
- Download the Latest zip for your platform
  - [Windows](https://github.com/wojtas3422/nophenia-mod-manager/releases/latest/download/mod_manager_windows.zip)
  - [Linux](https://github.com/wojtas3422/nophenia-mod-manager/releases/latest/download/mod_manager_linux.zip)
- Extract the zip
- Run the executable for your operating system
